# FitLog Library

FitLog Library is a workout library web application where users can browse different workouts, view workout details, add workouts to today's plan, and save workouts for later.

## Live Demo

[FitLog Library Live Website](https://fitlog-track.netlify.app/)

## GitHub Repository

[GitHub Repository](https://github.com/ashraful-islam11/assignment-6)

## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- React Toastify
- Next.js App Router

## Features

- Browse different workouts from the workout library
- View detailed information about each workout
- Add workouts to Today's Plan
- Save workouts for later
- Manage Today's Plan and Saved workouts
- Mark workouts as done
- Remove workouts from the plan or saved list
- Sort workouts by Duration, Calories, and Rating
- Responsive design for mobile, tablet, and desktop
- Toast notifications for workout actions
- Custom 404 page
- Loading state while workout data is loading

## Pages

- Home Page — `/`
- Workout Details — `/workOut/[workOutId]`
- My Plan — `/myPlan`

## Getting Started

First, clone the repository:

```bash
git clone https://github.com/ashraful-islam11/assignment-6.git
```

Go to the project folder:

```bash
cd assignment-6
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

To create a production build:

```bash
npm run build
```

## Project Goal

This project was created as a learning project to practice Next.js, TypeScript, React, Tailwind CSS, routing, state management, API data fetching, and responsive UI development.
